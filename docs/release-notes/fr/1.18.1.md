### Améliorations

- **Sur téléphone** :
  - la liste des machines virtuelles s'ouvre en cartes ;
  - les commandes qui attendent une sélection n'apparaissent qu'une fois quelque chose de sélectionné ;
  - le bandeau des opérations en bas laisse la place (elles restent dans les notifications) ;
  - les services de l'accueil défilent sur le côté ;
  - toutes les zones cliquables font au moins 24 px.
- **Avec beaucoup de machines** :
  - les noms longs sont coupés et visibles en entier au survol ;
  - regroupées par nœud, les machines ne répètent plus le nœud sur chaque ligne ;
  - les noms de colonnes restent visibles pendant le défilement.
- **En zoom à 200 % ou dans une petite fenêtre**, l'en-tête de page se réduit pour laisser voir le contenu.
- **Compte en lecture seule** : la barre d'une fiche ne montre que les commandes utilisables ; « Plus » liste toujours
  tout, avec la raison.
- **Fiche d'une machine** : chaque information n'apparaît qu'une fois (Essentiel puis Propriétés).
- **Toutes les ressources** : barre de commandes, filtre par type et même tableau que les autres listes.
- **Créer une ressource** propose aussi : cluster Kubernetes, nœud, image ISO, tâche d'automatisation, canal de
  notification et jeton d'API.
- **Création d'une machine ou d'un conteneur** : une page entière sous le bandeau, au lieu d'une fenêtre flottante.
- **Liste des machines** : la colonne Tags n'apparaît que si une machine en a ; les flèches de tri ne s'affichent que sur
  la colonne triée ou au survol.
- **Cohérence** : une seule présentation pour les erreurs ; des confirmations plus nettes ; des sections à titre sur
  toutes les pages d'une fiche.
- **Chargement** : chaque page de l'interface se charge à sa première ouverture, le premier écran arrive plus vite.

### Corrections

- La page **Performances** retrouve son en-tête.
- Un serveur injoignable, ou qui ne répond pas à temps, est signalé en français.
- **Clavier** :
  - le bandeau (recherche, notifications, compte) passe avant le menu ;
  - le volet des notifications garde le focus tant qu'il est ouvert ;
  - sur téléphone, le menu prend le focus à l'ouverture et le rend à la fermeture.
- **Accessibilité** : les boutons du compte et des notifications sont nommés d'après ce qu'ils affichent, et les
  pastilles d'état respectent le contraste minimal.
- L'onglet du navigateur porte le nom de la page ou de la ressource affichée.
- **Ressource disparue** : elle a une vraie page, avec le retour à sa liste et la recherche.
- **Accueil d'un cluster vide** :
  - accords justes ;
  - « Aucun pool de stockage » au lieu de « 0 Go utilisés sur 0 Go » ;
  - une invitation à créer la première machine.
- **État du cluster** : il compte les problèmes, au lieu d'afficher « Incident en cours » dès la moindre alerte.
- **Adresse d'une machine distante** : écrite avec « @ », elle ouvre bien la page demandée.
- Libellés : « Virtual machines » est écrit pareil partout en anglais, et le fencing est traduit.
