### Nouveautés

- **Bureau à distance dans le navigateur** : le bureau d'une VM Windows (ou de tout invité avec un serveur RDP) dans une
  fenêtre du navigateur, avec son presse-papiers, sans client à installer. Le nœud se connecte à l'invité dans une
  session isolée ; le mot de passe sert une fois et n'est jamais gardé. Le paquet recommande maintenant
  tigervnc-standalone-server et freerdp3-x11.
- **Diagnostic de connexion** : une VM peut-elle atteindre une autre VM ou une adresse sur un port ? Les pare-feu
  d'Hyperlite sur le chemin, l'emplacement des deux machines, un vrai essai depuis la VM et la vérification que la
  cible écoute, avec un verdict qui dit ce qui bloque.
- **Assistant** : des questions en langage courant, avec des réponses tirées des données d'Hyperlite, lues avec les
  droits de chacun et sans jamais rien changer. Désactivé tant qu'un administrateur ne l'active pas, avec un serveur
  de modèles local (Ollama, vLLM…) ou l'API Anthropic.
