### Nouveautés

- **La configuration du cluster en fichiers** : la configuration répliquée se lit maintenant comme des fichiers dans
  `/etc/hyperlite/cfs`, comme `/etc/pve` sur Proxmox VE : un fichier JSON par objet, `priv/` réservé à root, et
  `.members`, `.version` et `.quorum` calculés à la lecture. Un changement fait sur n'importe quel nœud s'y voit
  aussitôt. Les fichiers sont en lecture seule : les changements passent par l'API, le tableau de bord ou
  `hyperlite-admin`. Le paquet `fuse3` devient une dépendance.
