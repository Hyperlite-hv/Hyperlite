### À lire avant de mettre à jour

- **Version de passage obligatoire avant la 1.1.** La 1.1 rangera les fichiers d'Hyperlite là où Proxmox VE range
  les siens (`/var/lib/hyperlite`, `/etc/hyperlite`) au lieu de `/root/hyperlite`. Cette version ne déplace rien :
  elle prépare la mise à jour et son retour arrière pour que ce déplacement se fasse sans risque. Chaque nœud doit
  l'avoir avant de passer en 1.1.

### Nouveautés

- **`hyperlite-daemon`** : un service root qui exécutera, à terme, tout ce qui demande les droits root, derrière un
  accès local réservé. C'est la première étape pour que l'interface web tourne sans droits root, comme sur Proxmox.
  Il ne fait encore rien d'autre que répondre ; les opérations y passeront au fil des versions 1.1.x.

### Ce qui change

- **Une mise à jour ratée revient en arrière en réinstallant la version précédente**, au lieu de restaurer une
  archive, ce qui fonctionne quelle que soit l'organisation des fichiers. Vérifié sur une machine de test : une
  nouvelle version qui déplace les fichiers puis refuse de démarrer est remplacée par la précédente en deux minutes,
  toutes les données et tous les secrets intacts.

### Corrections et sécurité

- Une expression régulière sur le nom d'une image de conteneur pouvait faire ramer le serveur avec un nom piégé.
- La liste des images ISO du cluster ne montre plus le message d'erreur brut d'un nœud injoignable.
- Le nom d'une image ISO est vérifié là où il devient un chemin, sur ce nœud comme sur les autres.
