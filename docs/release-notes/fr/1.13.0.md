### Nouveautés

- **Préparation du déplacement des fichiers du nœud** : cette version ne change rien sur un nœud, mais sait revenir
  en arrière depuis la prochaine, qui rangera le certificat et les clés du nœud dans la configuration répliquée.
  Réinstallée par-dessus elle, elle remet d'abord ces fichiers dans `/etc/hyperlite`, sans
  jamais écraser un fichier déjà présent. La prochaine version ne pourra s'installer que par-dessus celle-ci.
