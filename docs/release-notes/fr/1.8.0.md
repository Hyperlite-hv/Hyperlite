### Nouveautés

- **Pare-feu des nœuds** (Centre de données › Pare-feu), comme les pare-feux de centre de données et de nœud de
  Proxmox VE : des règles d'entrée pour tout le cluster et pour chaque nœud, des groupes de sécurité et des ensembles
  d'IP, appliqués par nftables dans une table propre à Hyperlite. Un changement est vérifié par nftables, appliqué
  d'abord sur le nœud, et doit être confirmé depuis la page avant la fin du délai, sinon les règles précédentes
  reviennent ; une fois confirmé, tous les membres l'appliquent. Les membres du cluster, les connexions établies,
  ICMPv6 et le DHCP et le DNS des VM passent toujours. Désactivé tant qu'on ne l'active pas.
