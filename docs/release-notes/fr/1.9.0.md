### Nouveautés

- **Groupes de sécurité pour les VM et les réseaux** : le pare-feu d'une VM ou d'un réseau peut cocher des groupes de
  sécurité du pare-feu des nœuds (Centre de données › Pare-feu). Leurs règles s'appliquent au trafic entrant avant les
  siennes, et modifier un groupe change aussitôt toutes les VM et tous les réseaux qui l'utilisent. Un groupe qu'une
  VM utilise encore est gardé tant qu'elle s'en sert.
