### Nouveautés

- **Vue JSON** : un bouton `{}` dans l'en-tête d'une VM, d'un conteneur ou d'un nœud montre sa définition complète, à
  copier ou télécharger.
- **Page Étiquettes** (rubrique Identité) : toutes les étiquettes utilisées, avec le nombre d'objets qui les portent.
  Un clic liste ces objets ; un administrateur renomme une étiquette partout (fusionnée si le nouveau nom existe déjà)
  ou la retire partout.
- **Silences d'alertes** (sous les règles d'alerte) : sur tout, un nœud, une VM, un pool ou une règle, pour une période,
  avec un motif. Les alertes restent évaluées et journalisées, mais personne n'est prévenu.
- **Date de fin des comptes** (colonne « Fin » de la table des comptes) : à partir de ce moment, le compte ne peut plus
  se connecter et ses sessions, jetons d'API et sessions Terminal cessent de fonctionner. Ses droits et ses fichiers
  restent : repousser la date le rétablit.
- **Contraste élevé** (Préférences > Contraste : Système, Élevé, Standard), en thème sombre comme en clair.

### Corrections

- Création d'une VM ou d'un conteneur : la page de création est de nouveau sous l'en-tête, sur toute la largeur (elle
  s'affichait à moitié hors de l'écran).
