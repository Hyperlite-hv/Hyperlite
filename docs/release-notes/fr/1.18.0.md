### Nouveautés

- **Nouvelle interface, organisée comme une console.**
  - En haut, un bandeau : la recherche, les notifications (opérations en cours et alertes) et le compte.
  - À gauche, le menu des services : Créer une ressource, Accueil, Toutes les ressources, Tous les services, puis les
    services épinglés. Une étoile épingle un service ; le menu se réduit aux icônes.
  - **Accueil** : les services, les ressources ouvertes récemment, l'état du cluster avec sa capacité, ce qui est à
    surveiller et les opérations en cours.
  - **Tous les services** les range par famille ; **Toutes les ressources** liste les machines, les conteneurs et les
    nœuds dans un seul tableau.
- **Listes** (machines virtuelles, nœuds, conteneurs, stockage, réseau, sauvegardes) :
  - une barre de commandes au-dessus : créer, actualiser, exporter en CSV ; pour les machines virtuelles, démarrer,
    redémarrer, arrêter, supprimer ou migrer la sélection ;
  - un filtre sur tous les champs et des filtres qui se lisent comme une phrase (« Nœud égal à », « État égal à ») ;
  - un menu « … » sur chaque ligne ; les machines virtuelles sont regroupées par nœud.
- **Fiche d'une machine, d'un conteneur ou d'un nœud** :
  - ses pages dans un menu à gauche, au lieu d'onglets ;
  - une barre de commandes : une commande indisponible reste visible et dit pourquoi, les autres sont sous « Plus » ;
  - une vue d'ensemble qui commence par un bloc **Essentiel** (avec une vue JSON), puis les **Propriétés** par sujet,
    chacune avec un lien vers la page qui la modifie, et la **Supervision** avec ses graphiques.
- **Apparence** : nouvelles couleurs, police Inter, icônes d'une seule couleur et nouveau logo. Le thème suit celui du
  système, sauf si vous choisissez clair ou sombre.
- Toutes les adresses de page et tous les liens existants continuent de fonctionner.
