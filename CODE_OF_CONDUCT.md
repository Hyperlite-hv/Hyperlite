# Code of conduct

We want Hyperlite to be a friendly, harassment-free project for everyone.

## Expected behavior

- Be respectful and constructive; assume good intent.
- Give and accept technical criticism graciously; focus on the code, not the person.
- Keep discussions on topic.

## Unacceptable behavior

- Harassment, insults, discriminatory language or personal attacks.
- Publishing other people's private information.
- Sustained disruption of discussions or pull requests.

## Enforcement

Maintainers may edit, hide or remove comments, issues and pull requests that violate this code, and may block repeat offenders. To report a problem, contact the maintainer through the repository (a private security advisory or a message to the owner's GitHub profile).
