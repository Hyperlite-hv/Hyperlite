VMs get Schedules: start, shut down, stop or snapshot a VM at a set time on chosen weekdays, in the node's local time. The node hosting the VM runs them, so they follow it when it migrates. A snapshot schedule keeps its last N snapshots and never touches those taken by hand. A run missed by more than 30 minutes is skipped and journaled. Power actions need the vm.power privilege on the VM, snapshots vm.snapshot.
