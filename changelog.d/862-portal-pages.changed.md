- The pages of the virtual machines and the nodes follow the console (#862). The list of virtual machines has a command bar (Create, Manage view, Refresh, Export to CSV, then Start, Restart, Stop, Force stop, Delete and Migrate, which wait for a selection), filters read as sentences ("Node equals", "State equals", "Tag equals"), grouping by node by default with one head per node, and a "…" menu on every row. The overview of a machine, a node and a container opens with an "Essentials" block (with a JSON view); machines and nodes then have Properties, grouped by subject with a link to the page that changes each one, and Monitoring with their charts. Icons are drawn in one colour; the coloured tiles are gone.
