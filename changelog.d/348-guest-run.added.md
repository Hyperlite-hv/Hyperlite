VMs gain two pages through their guest agent. Guest system shows the OS, kernel, host name, time zone, signed-in users and file systems with their usage. Run command runs a script in the guest's shell (sh, bash, PowerShell or cmd), with ready-made scripts and a timeout of up to 2 minutes, and shows its exit code, output and errors; nothing needs to be open on the VM's network. Running a command needs the new "vm.exec" privilege, which no predefined role holds. Every run is written to the journal without the script itself.
