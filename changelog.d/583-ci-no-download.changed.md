- **The CI no longer downloads the same packages in every job** (#583). The runner's Ubuntu mirror made `apt-get install` take up to 22 minutes, and `playwright install --with-deps` up to 14, in jobs whose tests took 3: a full run took 20 to 50 minutes. The packages a job installs are kept as the `.deb` files of the runner image they were fetched on (`.github/actions/apt-install`), and Chromium per Playwright version; only pushes to test and master write them, a pull request only reads them. The workflows are checked by zizmor in the CI (template injection, permissions, pinned actions, caches), and the publication receives its four secrets by name instead of every secret of the repository.
